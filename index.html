⚗️ EXPERIMENTAL SYSTEMS

Visual Lab

An experimental environment where I explore geometry, procedural visuals and interactive systems.

⬡ Procedural geometry — 4D structures projected into 3D space

⬡ Real-time rendering — D3.js + canvas animation loops

⬡ Symbolic representation — geometry as a language for cosmos

⬡ Interactive systems — click, hover, state-driven behavior

These experiments feed directly into Archeoscope — testing how geometry, time and perception can be rendered in real time.


TESSERACT — 4D HYPERCUBE · ORTHOGONAL PROJECTION

click to pause · hover to interact


A tesseract is a 4-dimensional hypercube projected into 3D space. Each vertex represents a coordinate in 4D — rendered here in real time using D3.js and a custom rotation engine.


Adapted from milosz's hypercube · D3 parallel coordinates
